# AI-tool disclosure template

**Publication status: USER CONFIRMATION REQUIRED**

The final disclosure must list only tools and services the team actually used.
No tool name is inferred from repository artifacts. The user must confirm the
complete list and roles before publication.

| Tool | Role | Human verification | Scientific-number source |
|---|---|---|---|
| USER CONFIRMATION REQUIRED | Specify whether used for code, writing, figures, translation, or review | Describe the human review performed | Executed files under `results/`; no AI-generated number is accepted |

Required final confirmation:

- actual assistant/service names and versions if known;
- which artifacts each tool influenced;
- which outputs were manually reviewed or executed;
- confirmation that every scientific number comes from checked result artifacts;
- confirmation that no confidential, personal, or restricted data were supplied.
